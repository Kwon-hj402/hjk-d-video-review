# 성능과 해석

## 평가 조건

best.pt를 confidence=0.25, imgsz=640, retina_masks=true로 추론했습니다. 검증 50장과 시험 3장의 승인 마스크와 예측 내강 합집합을 원본 640×448 해상도에서 비교했습니다. 예측 픽셀 임계값은 0.5입니다.

Dice = 2|G∩P|/(|G|+|P|), IoU = |G∩P|/|G∪P|입니다. 먼저 프레임별로 계산한 뒤 양성 프레임에서 산술평균했습니다. 전체 픽셀을 합쳐 구한 micro 점수가 아닙니다.

| 항목 | 검증 0005 | 시험 0006 |
|---|---:|---:|
| 전체 | 50 | 3 |
| 양성 | 49 | 2 |
| 양성 평균 Dice | 0.9652645 | 0.8566760 |
| 양성 평균 IoU | 0.9329589 | 0.7632836 |
| 음성 | 1 | 1 |
| 음성에서 예측도 비어 있음 | 1/1 | 1/1 |

당시 저장 마스크의 픽셀을 재계산했고, 공개 가중치로 53장을 다시 추론해 같은 결과를 확인했습니다. 재평가는 학습을 다시 하거나 모델을 수정한 작업이 아닙니다.

## 빈 마스크 규약

두 마스크가 모두 비어 있으면 Dice·IoU는 수식상 0/0입니다. 대표 결과는 양성 일치도와 음성의 빈 예측 건수를 분리합니다.

기존 review.json은 두 빈 마스크를 0으로 처리하여 전체 Dice 평균을 검증 0.9459592, 시험 0.5711174로 기록했습니다. 두 빈 마스크를 1로 처리하면 0.9659592와 0.9044507입니다. 서로 다른 규약의 수치를 직접 비교하지 않습니다.

original_review.json은 당시 기록입니다. 평가 메모의 “One test frame”은 실제 시험 3장 구성과 맞지 않는 오래된 문구입니다. 현재 해석에는 split_report.json, 원본 마스크와 metrics.json을 사용합니다.

## Ultralytics 내부 검증

best.pt 내부 train_metrics와 87 epoch 로그가 일치합니다.

| mask 지표 | 값 |
|---|---:|
| Precision / Recall | 1.0000 / 1.0000 |
| mAP@0.50 | 0.9950 |
| mAP@0.50:0.95 | 0.90387 |

mAP는 IoU 기준별 인스턴스·마스크 평가입니다. confidence=0.25에서 계산한 프레임별 Dice와 정의가 다릅니다. Precision=1, Recall=1을 모든 픽셀 또는 모든 새 영상의 정확도로 읽지 않습니다. [공식 설명](https://docs.ultralytics.com/guides/yolo-performance-metrics/)

## 발표에서 설명할 한계

- 검증 영상은 학습과 분리했으나 모델 선택에 사용한 내부 자료입니다.
- 시험은 3장(양성 2장)입니다. 외부 일반화 성능을 안정적으로 평가하기에 부족합니다.
- 제공자의 여러 영상으로 대상자 독립 평가를 하지 않았고, 인접 프레임은 시간적으로 상관됩니다.
- 평가 참조는 사용자 승인 주석입니다. 전문가 합의·반복 주석 신뢰도를 측정하지 않았습니다.
- Dice가 높아도 직경의 mm 오차, FMD% 오차, ICC, Bland–Altman 결과를 알 수 없습니다.
- D 산출 비율 12,276/15,133은 처리 결과의 산출 가능 비율이며 정확도가 아닙니다.

발표 표현: “영상 단위 내부 검증에서 양성 49프레임의 평균 Dice는 0.9653이었다. 시험 및 대상자 독립 자료가 부족하여 탐색적 결과로 해석하였다.”
