# 데이터와 레이블링

## 추출과 후보 선별

사용자 제공 경동맥 초음파 AVI 7개(0002, 0004, 0005, 0006, 0007, 0008, 0009)를 디코딩했습니다. 모두 640×448, 28.775 fps이며 총 15,133프레임입니다. 시간은 0부터 시작하는 프레임 번호/fps로, ECG 위상이나 커프 해제 시각과 동기화한 값은 아닙니다.

전체 크기 PNG는 디코딩한 픽셀을 보존합니다. 원본 MP42 영상의 압축을 되돌린다는 뜻은 아닙니다.

초기 후보 400장은 선명도(Laplacian 분산), 대비(P95−P5), 암부·포화 비율, 어두운 띠의 가시성·규칙성, 시간 간격과 모양의 다양성으로 선별했습니다. 점수 ROI는 [100,125,540,365], 점수 하한은 0.50, 시간 간격은 약 0.6초 이상입니다. 실제 최소 간격은 대부분 18프레임(약 0.626초)입니다. 이 점수는 의학적 적합성 판정이나 내강 레이블이 아닙니다.

어두운 띠의 화질 지표를 구할 때 Gaussian blur를 사용하지만, 저장한 원본이나 학습 입력에 적용한 필터는 아닙니다.

최종 승인 215장과 초기 후보 400장의 교집합은 **27장**입니다. 이후 전체 영상에서 추가로 주석한 프레임을 포함합니다. 따라서 “400장 중 215장을 승인했다”고 서술하지 않습니다.

## 수동 주석 과정

1. 한글 로컬 작업대에서 프레임을 열고 내강을 둘러싸는 꼭짓점을 클릭합니다.
2. Enter로 다각형을 닫고, 꼭짓점을 이동·추가·삭제하여 윤곽을 수정합니다.
3. 확인한 주석을 승인합니다. 내강이 없다고 판단한 프레임은 음성으로 승인합니다.
4. status=approved인 주석만 학습 스냅샷으로 복사합니다. 미승인 자동 제안과 초안은 제외합니다.

대상은 혈관 **내강(lumen)** 한 클래스입니다. IMT, 내중막, 외막을 별도 클래스로 표시하지 않았습니다. 사용자 승인 주석을 평가 참조로 사용했으며, 독립 전문가 합의 주석은 아닙니다.

## 각 파일의 의미

| 형태 | 저장 위치 | 사용 |
|---|---|---|
| 원본 PNG | pipeline/data/export/current/images | 색칠하지 않은 모델 입력, 640×448 |
| 다각형 JSON | pipeline/data/annotations | 원본 픽셀 좌표와 승인·음성 여부 |
| YOLO TXT | pipeline/data/export/current/labels | 학습용 정규화 다각형 좌표 |
| 0/1 마스크 PNG | pipeline/data/export/current/masks | 승인 다각형을 Pillow로 채운 내보내기·평가 참조 |
| 0/255 표시 마스크 | research/mask_display | 검정 배경·흰 내강으로 보기 위한 자료 |
| 주석 오버레이 | research/annotations | 원본에 승인 윤곽과 꼭짓점을 겹친 설명 자료 |
| 예측 마스크·비교 | research/evaluation | 검증·시험 53장의 모델 출력 |

YOLO TXT 형식은 `0 x1/W y1/H x2/W y2/H ...`입니다. **클래스 ID 0=lumen**과 **마스크 픽셀 0=배경, 1=내강**은 서로 다른 규약입니다.

모델은 원본 PNG와 YOLO 다각형 TXT를 읽고 내부에서 학습 마스크를 구성합니다. 색칠한 오버레이를 모델 입력으로 학습하지 않았습니다. PNG 평가 참조와 모델 내부 마스크 생성의 경계 래스터화는 미세하게 다를 수 있습니다.

음성 15장은 빈 YOLO 레이블과 모든 픽셀이 0인 마스크를 갖습니다. 승인 215장은 양성 200 / 음성 15이며, 미승인 초안 5장을 학습에서 제외했습니다.
